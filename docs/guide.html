특허, 한 장으로 읽기

브리핑에 나오는 청구항·종속항·패밀리 같은 말을 한 장에 모았어요.

← 특허 브리핑 보러 가기

01특허 문서는 네 부분

  • 서지사항번호·출원인·날짜. 책의 표지예요.
  • 초록발명을 한 문단으로 줄인 소개글.
  • 명세서배경·실험·도면을 담은 자세한 설명서.
  • 청구범위 ★권리의 경계를 적은 문장들(청구항).

권리의 범위는 설명서가 아니라 청구항이 정해요. 그래서 특허는 청구항부터 읽어요.

03특허의 일생

  1. 출원특허청에 신청
  2. 공개약 1년 6개월 뒤 누구나 볼 수 있게 공개 (아직 심사 중)
  3. 등록심사를 통과해 권리가 생김
  4. 만료출원일부터 20년

브리핑의 공개 특허는 아직 심사 중이고, 등록 특허는 권리가 확정된 것이에요.

02청구항은 권리의 울타리

청구항 1 · 독립항양극 + 음극 + 분리막 + 세라믹 코팅
청구항 2 · 종속항+ 세라믹은 알루미나
청구항 3 · 종속항+ 코팅 두께 1~5㎛

안쪽으로 갈수록 조건이 늘고 범위는 좁아져요

예시 · 이해를 돕는 가상 청구항

  1. 【1】양극, 음극, 분리막을 포함하고, 분리막 표면에 세라믹 코팅층이 있는 이차전지.
  2. 【2】제1항에 있어서, 세라믹은 알루미나인 이차전지.
  3. 【3】제2항에 있어서, 코팅층 두께가 1~5㎛인 이차전지.
  • 독립항다른 항을 빌리지 않고 혼자 서는 청구항. 조건이 가장 적어 범위가 가장 넓어요. 보통 청구항 1.
  • 종속항"제○항에 있어서"로 시작해 조건을 더한 청구항. 범위는 좁지만, 넓은 항이 무효가 돼도 살아남는 예비 울타리예요.
  • 침해남의 제품이 청구항의 조건을 하나도 빠짐없이 다 가져야 침해예요. 그래서 조건이 적은 청구항일수록 강해요.

경쟁사 전지가 알루미나 코팅 8㎛라면 → 청구항 1·2는 해당, 청구항 3은 두께가 달라 해당 안 됨.

05브리핑에 나오는 말

패밀리
같은 발명을 여러 나라에 낸 묶음. 여러 나라에 낼수록 회사가 중요하게 본다는 신호예요.
우선권
첫 출원 후 12개월 안에 다른 나라에 내면 첫 출원 날짜를 인정받아요.
PCT
국제출원. 한 번 내 두고 약 30개월 안에 들어갈 나라를 골라요.
IPC
기술 분류 코드. H01M = 전지, H01L = 반도체 소자, H02J = 충전·전력망.

읽는 순서① 제목·초록으로 무슨 발명인지 → ② 청구항 1로 권리의 핵심 → ③ 종속항의 숫자·소재로 회사가 노리는 구체적 조건

이해를 돕기 위한 단순화예요. 실제 권리 판단은 변리사와 상의하세요.
